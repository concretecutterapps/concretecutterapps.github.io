History and project reference

Find previous calculations, group them by project and share documentation.

Use

Project / reference is optional on calculator screens. Previous project names are suggested as you type, and the reference is stored with the next calculation.

Options

History can be grouped by date or project. Select entries to total weight-capable records, share as text or PDF, add/edit notes, and delete selected entries or all history.

Stored data

Saved results retain the values, units and localized result text recorded when the calculation was made; changing settings later does not rewrite old entries.

Use the project field as a work reference

Project / reference makes it easier to find calculations from the same job without changing the calculation itself. A short internal reference such as “Job 2417 – stair opening” can be used on several calculations and later grouped in History.

Documentation after the calculation

History entries can be grouped, given notes and shared as text or PDF. This makes them useful as work documentation, but a saved record shows what was calculated; it does not prove that dimensions, method or safety controls were later verified physically.

Why original units are preserved

A history entry keeps the values, units and result wording used when the calculation was created. Changing between metric and imperial or choosing another app language later therefore does not rewrite the meaning of older documentation.
