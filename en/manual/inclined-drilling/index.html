Inclined drilling

Calculate drilling angle and length for a known offset, obstacles, or floor-to-wall drilling.

How it works

Three modes: Known offset uses thickness and centre offset. Against obstacle uses thickness, drill diameter and lower/upper obstacle. Floor + wall uses wall thickness, drill diameter and required vertical height difference.

Results

Angle is shown as deviation from 90° to the surface. Results include the relevant drilling length and geometry. Known offset and Against obstacle can open Angle mount with the calculated angle and thickness.

Practical check

With two obstacles the app finds an allowed angle range when the opening fits. If it is too tight, compromise options are shown; these are not collision-free solutions.

When angled drilling solves a field problem

Angled drilling is used when entry and exit points are not directly opposite each other, or when the drilling path has to clear an obstacle. The feature makes the geometry visible before the stand is fixed so angle, offset and drilling length can be checked together.

The angle reference matters

The app reports the angle as deviation from 90° to the surface. Use the same reference when marking and setting up the rig. A small angle error can create a large offset on the opposite side of a thick construction.

Practical check

Measure from fixed references on both sides, verify the intended exit point and assess the complete drilling path rather than only the centre mark. Obstacles, core diameter, stand and motor clearance, and the side from which measurements were taken must be clear before drilling.
