Core drilling calculations

Plan angled core drilling with a clearer view of drilling distance, offset and the measurements needed before setting up the rig.

Why drilling angle matters

When a core hole passes through a structure at an angle, the drilling path is longer than the straight thickness of the structure. The entry and exit points are also offset from each other. That difference becomes more noticeable as the structure gets thicker or the angle becomes steeper.

Measure the actual drilling path

Start with the thickness through the intended drilling path and the position of obstacles or the required exit point. Check that the drill rig, stand and core bit have enough room for the planned setup. A calculation supports planning, but the conditions on site must always be confirmed before drilling.
