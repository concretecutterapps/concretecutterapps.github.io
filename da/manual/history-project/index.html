Historik og projekt

Find tidligere beregninger, gruppér dem efter projekt og del dokumentation.

Use

Projekt / reference er valgfrit på beregningsskærmene. Tidligere projektnavne foreslås under indtastning og gemmes med næste beregning.

Options

Historik kan grupperes efter dato eller projekt. Vælg poster for at summere vægtposter, dele som tekst eller PDF, redigere noter og slette valgte eller alle poster.

Stored data

Gemte resultater beholder værdier, enheder og lokaliseret resultattekst fra tidspunktet for beregningen.
